W: Organizacja wydarzeń rekreacyjnych :: Planujesz zajęcia i atrakcje dla gości korzystających z kempingu. | Ochrona środowiska naturalnego :: Pilnujesz, żeby działalność kempingu nie szkodziła otaczającej przyrodzie. | Zarządzanie rezerwacjami :: Prowadzisz system rezerwacji miejsc na terenie kempingowym.

@1945
M: Planowanie trasy dystrybucji :: Układasz trasę tak, żeby dotrzeć do jak największej liczby odbiorców. | Prezentacja oferty :: Przedstawiasz w kilku słowach, czego dotyczy reklama lub ulotka. | Segmentacja odbiorców :: Rozpoznajesz, które miejsca i osoby odpowiadają grupie docelowej ulotki. | Rozliczanie rozdanego nakładu :: Liczysz i raportujesz, ile materiałów faktycznie udało się rozdać.
W: Obsługa klienta na ulicy :: Odpowiadasz na pytania przechodniów dotyczące rozdawanej oferty reklamowej. | Przepisy o reklamie :: Wiesz, gdzie wolno rozdawać materiały reklamowe, a gdzie tego zabroniono. | Zbieranie informacji zwrotnej :: Notujesz reakcje odbiorców, żeby przekazać je zamawiającemu akcję.

@1946
M: Techniki laboratoryjne biochemii :: Wykonujesz doświadczenia badające reakcje chemiczne zachodzące w komórkach i tkankach. | Analiza wyników badań :: Przetwarzasz dane pomiarowe, żeby sprawdzić, czy hipoteza się potwierdziła. | Praca z odczynnikami chemicznymi :: Bezpiecznie przygotowujesz i stosujesz roztwory używane w prowadzonych eksperymentach. | Badanie białek i enzymów :: Badasz budowę i działanie cząsteczek biologicznych w organizmie żywym.
W: Opracowywanie nowych substancji :: Projektujesz i testujesz związki, które mogą stać się lekami. | Statystyka w badaniach biologicznych :: Analizujesz dane eksperymentalne metodami statystycznymi, żeby ocenić ich wiarygodność. | Pisanie publikacji naukowych :: Opisujesz wyniki badań w formie przyjętej w czasopismach naukowych.

@1947
M: Metody fizyczne w biologii :: Stosujesz techniki fizyczne do badania struktury komórek i białek. | Modelowanie procesów biologicznych :: Budujesz modele matematyczne opisujące zachowanie żywych układów biologicznych. | Analiza danych eksperymentalnych :: Przetwarzasz wyniki pomiarów, żeby wyciągnąć z nich wnioski naukowe. | Obsługa aparatury pomiarowej :: Korzystasz ze specjalistycznego sprzętu do badania cząsteczek i komórek.
W: Programowanie naukowe :: Piszesz skrypty do analizy i wizualizacji danych biologicznych. | Mikroskopia zaawansowana :: Obserwujesz struktury komórkowe przy użyciu specjalistycznych mikroskopów naukowych. | Pisanie raportów badawczych :: Dokumentujesz metodykę i wyniki prowadzonych doświadczeń naukowych.

@1948
M: Diagnostyka laboratoryjna :: Analizujesz próbki krwi i tkanek, żeby wykryć objawy choroby. | Interpretacja wyników badań :: Oceniasz, czy wyniki testów wskazują na nieprawidłowości u pacjenta. | Kontrola jakości badań :: Sprawdzasz, czy wynik badania jest wiarygodny, zanim przekażesz go lekarzowi. | Obsługa aparatury diagnostycznej :: Korzystasz ze sprzętu do analizy krwi, hematologii i biologii molekularnej.
W: Genomika diagnostyczna :: Analizujesz materiał genetyczny w poszukiwaniu przyczyn danej choroby. | Komunikacja wyników medycznych :: Przekazujesz lekarzom wyniki w sposób zrozumiały i przydatny klinicznie. | Udział w badaniach klinicznych :: Wspierasz testowanie nowych metod diagnostycznych lub terapii medycznych.

@1949

W: Nauczanie i mentoring :: Uczysz studentów oraz młodszych specjalistów metod pracy badawczej. | Pisanie publikacji naukowych :: Opisujesz wyniki badań w artykułach recenzowanych przez innych naukowców. | Współpraca międzynarodowa w badaniach :: Uczestniczysz w projektach badawczych razem z zespołami z innych krajów.
